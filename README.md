# 同桌画室 Paintmates · 网页版

这是同桌画室网页版（`0.4-web.3`，房间协议 v4）的静态构建产物，用于在浏览器（含 iPad Safari）里加入同一个画室：共享创作画面、语音，并调音。

- 入口：https://duyv0826.github.io/paintmates-room/
- 桌面端为 Windows 版本，不在本仓库内。
- 每个房间最多 6 人，通过邀请码或邀请链接加入。
- 房间依赖可访问的 PeerServer 信令服务；部分网络还需要有效的 TURN 中继，公共默认中继不保证可用。

本仓库只包含构建产物（HTML/JS/CSS/图标/第三方声明），不含源码与凭据。首次访问需要授权麦克风与屏幕采集；换域名后浏览器会重新申请权限。
